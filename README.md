# LaundryDesk (RAP Laundry)

Website Pengelolaan Cuci Pakaian Offline berbasis Laravel 12 & MySQL.

## Ringkasan Proyek
Aplikasi pengelolaan operasional laundry untuk skala kecil hingga menengah yang dirancang untuk bekerja secara lokal/offline tanpa ketergantungan internet.
